# WolfGym 实验协议

统一口径：2026-10-01。本文描述当前组合监管任务、分析方法和实验边界；
执行进度见 [EXPERIMENT_STATUS.md](EXPERIMENT_STATUS.md)。当前实验已由用户暂停。
协议、代码或工程验收的存在不表示正式 test 已放行，也不授权启动实验。

## 研究问题与权威来源

研究角色是具有有限干预预算的模拟市场监督者：能否根据公开证据选择对象和时机，
减少普通参与者的反事实财富损害，并控制正常市场的财富与交易代价？
主结果是闭环监管 CR。RF/AE/IS 静态诊断和单战术研究属于历史接口与机制对照，
不代替当前组合任务，也不把旧标签重新命名为新任务结果。

当前可执行入口是 [CombinationGymEnv](../src/wolfgym/env/combination.py)，
其数值和源码指纹由 [运行合同](../src/wolfgym/env/combination_v51.json) 约束，
划分由 [采样协议](../src/wolfgym/benchmark/combination_splits_v1.json) 约束。
配置名称中的版本号是机器兼容性标识，不是并行有效的多套研究设定。
市场与观测细节分别见 [MARKET_CONTRACT.md](MARKET_CONTRACT.md) 和
[LANGUAGE_OBSERVATION_CONTRACT.md](LANGUAGE_OBSERVATION_CONTRACT.md)。

## 固定人口、攻击与权限

| 项目 | 当前设定 |
| --- | --- |
| 人口 | 500 名参与者：490 名普通参与者、10 名操纵者；另计 3 个做市账户 |
| 市场 | 3 资产，30 个模拟交易日，`wolfgym-market-ledger-v8` |
| 普通初始财富 | 每人 10,000，共 `W0=4,900,000`；初始股票份额 50% |
| 操纵者初始财富 | 每人 50,000，共 500,000；初始股票份额 20% |
| 操纵者资源 | 人口占 2%，参与者初始资金占 9.2593%；`high_degree` 放置 |
| 日资源上限 | 每操纵账户提交名义订单额 ≤ 自身初始财富；日消息强度合计 ≤ 1.8 |
| 组合攻击 | 同一群体按 `campaign` 在 S1/S2/S3/S4/WAIT 间切换，一天选择一种群体战术 |
| 钱包 | 各成员跨战术复用同一现金和持仓，不在切换时重新注资；无无限跨成员资金池 |
| 主动作 | `Discrete(4)`：WAIT，或对当前公开三资产之一单日 FREEZE |
| 行政预算 | 初始 12；WAIT 费用 0，每次 FREEZE 费用 4，最多三次 |
| 动作效果 | FREEZE 限制目标资产相关消息及真实/spoof/wash 订单，可能影响普通参与者；市场日结束释放 |
| 决策时序 | 决策索引 0–29，先读公开观测再行动；动作作用于下一收盘 |

“2%”不能脱离财富、网络位置、库存和日资源上限单独描述。S2 是历史机制对照，
不再是主任务。观察到多种战术活动不证明四种战术分别有效或存在因果协同。
其他人口、比例或权限需要独立合同，不进入主成绩。

非法类型、越界和预算不足在推进任何世界前拒绝。所有完整 episode 运行 30 日，
事件不提前终止。第 30 日 `terminated=True, truncated=False`；外部时间截止导致的
truncated 轨迹是不完整结果。模型评测奖励始终为零。

## 三世界与损害定义

每个策略 episode 维护同初始社会的 R、WAIT、policy 三个配对世界：

- R：同初始账户和禀赋、共同外部市场随机流，关闭攻击且监管 WAIT；干预时 R 不变。
- WAIT：该评测条件下的无干预轨迹。
- policy：相同条件和续跑随机流下实施策略的轨迹。

attack 条件启用组合群体。normal 条件保留同一人口及账户禀赋，关闭攻击，只重置
普通决策和社会传播随机流；不删除十个账户，也不把它们转换为普通交易者。
R 仅是计分参考，不另计为一个正常样本。历史研究中 R/N 的混合正常口径不能
直接冒充当前 benchmark normal 成绩。

保护对象固定为初始 490 个普通账户。各世界使用共同当日外生基本面估值：

```text
V_i(t) = cash_i(t) + Σ_a holdings_i,a(t) × fundamental_a(t)
H(t) = Σ_i max(V_i^R(t) − V_i(t), 0) / W0
G(t) = Σ_i (V_i^R(t) − V_i(t)) / W0
```

H 保留个体损失；G 检查群体净缺口。它们不是价格跌幅，也不允许赢家收益抵消 H。
基本面、参考账户、隐藏角色、真实攻击目标、未来状态和 H/G/事件分数只属于可信
宿主，不能作为策略输入或工具。完整轨迹之后的 `evaluation_result()` 也仅供宿主。

复合重大损害事件 `C = W OR T OR F`，首次触发后锁存：

| 分量 | 固定定义 |
| --- | --- |
| W：持续财富损害 | 连续两个收盘，每日 H **严格大于** 0.0038562228090846347 且 G ≥ 0.001；不要求同一批受害人 |
| T：严重个体损害 | 任一收盘至少 1% 的初始普通账户各自相对 R 损失 ≥ 自身初始财富 10%；490 人时向上取整为 5 人 |
| F：持续交易功能损害 | 连续两日，实际与 R 的普通 requested notional 各 ≥ W0 的 0.1%；R 未服务率 ≤ 50%，实际未服务率比 R 高至少 50 个百分点 |

未服务率为 `(blocked + unexecuted) / requested`。实现见
[combination_task.py](../src/wolfgym/evaluation/combination_task.py)。
该事件表示本协议内的模拟投资者保护失败，不是现实金融系统崩溃的通用定义。
当前正例主要来自 W，T/F 的独立致害与可干预性仍缺充分证据。

## 划分、统一输入与主指标

| 划分 | 初始社会数 | episode 数 | 根种子，含两端 | 用途 |
| --- | ---: | ---: | --- | --- |
| train | 1000 | 2000 | 30000000–30000999 | 训练、开发、提示和成本试跑 |
| validation | 128 | 256 | 40000000–40000127 | 有界候选、检查点和非 LLM 对照选择 |
| test | 256 | 512 | 50000000–50000255 | 最终冻结后的完整评测；尚未运行 |

每个社会同时有 normal/attack，两条件权重各 0.5。所有条件、策略、checkpoint 和
续跑继承同一 group/split。范围低于 30000000 的历史和工程种子不进入主划分。
`episode_plan(split)` 使用稳定哈希顺序；开发子集按首次出现的 group 取完整社会，
不按结果筛选。`reset(seed)` 不能换题，换题需构造下一条清单 episode。

主输入 `public-structured-v1`：当前及此前最多四帧公开观测、缺失历史 mask、
全部三资产、至多五个当期实体、7 个市场数值、6 个社会数值、按资产的选定消息
count/reach/present、预算/合法动作、完整已执行干预记录。ID 在 episode 内稳定，
实体按 ID 对齐而非按排名。主输入不含消息正文、kind 或逐条发送者关联。
数值保持源公开值，语义说明只解释单位和权限，不提供报警阈值、推荐策略或攻击日历。
学习与 LLM 使用同一规范公开信息；算法内部编码另行记录。

```text
ΔH(g,c,π) = H_WAIT(g,c,30) − H_policy(g,c,30)
B(g,π) = 0.5 ΔH(g,normal,π) + 0.5 ΔH(g,attack,π)
主指标 = mean_g B(g,π)
```

报告时乘 100 换成百分点（pp），负收益不截断。1:1 权重不代表现实攻击发生率。
主表必须同时报告 normal/attack 的 ΔH、剩余 H、G、C/W/T/F、防止/新增事件、
动作次数/日程/预算、普通 requested/blocked/unexecuted/executed notional 配对变化、
无效动作、推理费用与未知费用预留。成交减少不直接等于福利损失。

统计单位是初始社会。同社会两条件、策略、随机重复和训练实例共同保留，重复先在
社会内平均；512 条 test episode 不能当成 512 个独立样本。主要配对 bootstrap
固定 20,000 次、RNG 20260926。初始化存在已识别的 lag-13 随机输入复用，补充按
`root_seed % 13` 整链重采样、按抽中社会数归一，20,000 次、RNG 20260927。
保留点估计和两套区间，不挑较窄者；仅 13 条链，不能声称精确覆盖或严格独立。
非连续开发根使用其实际占用链，不能直接套仅支持连续根的函数。

## 强基线和已固定学习方法

基线族共 21 个实例：WAIT；随机三次行动的 3 个 RNG 重复；四套日期
`{0,5,10}/{3,8,13}/{5,10,15}/{8,13,18}` × 三个初始公开资产槽；day 3
一次选目标后的后三套日期；报警锁定和报警刷新。全部候选保留。

`alarm_refresh` 使用冻结检测器，分数严格超过 0.6739093390044616 首次报警后，
于报警日、+5、+10 行动，每次重新选择可见消息 audience_reach 合计最大的资产；
无选定消息时按 `return_3d`、`volume_zscore`、公开资产 ID 排序，平局取较大 ID。
检测器分数不是已校准的 collapse 概率。P* 已按 validation 固定为 `alarm_refresh`，
日期对照固定为 `date_8_slot_1`，即决策日 8/13/18、初始槽位 1。

动态策略相对捷径的实用差异尺度为 0.02 pp，是模拟研究容忍度；validation
筛查仍未决，不能称等效或动态能力已独立确认。策略选择基于 validation 等权收益，
平局依次取较低成本、固定 ID 字典序。

已完成的学习方法均使用五帧 1895 维编码、预算 mask、公开输入，不训练背景群体：

- PPO：MaskablePPO，128×128 前馈网络；seed 11/22/33 各 2000 episode，
  每 500 episode 验证；终值有符号 ΔH×1000，其余奖励零。lr 0.0003，batch 120，
  10 epochs，gamma/GAE lambda=1/1，clip 0.2，entropy 0.01，value 0.5，grad cap 0.5。
- BC：64 个 train 社会的 3840 条规则示范，2891 个预算可选择帧参与拟合；
  最终选择固定原数据、普通 masked CE、128×128 tanh MLP、Adam lr 0.0003、
  batch 128、2000 更新，seed 11/22/33。seed 11 参与过开发选择，另外两 seed
  从头训练；验证最终模型一次，不再选检查点。权重平衡与学生状态聚合的负结果保留，
  不增加第三轮。三 seed 表示同一数据上的优化重复，不是独立市场采样。

1895 维编码保留公开身份的 UTF-8 字节和窗口内实体对应，采用固定单位缩放与
`sign(x)*log1p(abs(x))` 后转 float32；不在 validation/test 上拟合归一化。
具体软件版本、来源文件和数据/模型指纹以各本地运行 manifest 为准。

## LLM 组件与正式实验门禁

| 系统 | 是否/何时 FREEZE | 目标选择 |
| --- | --- | --- |
| RR | 冻结公开报警与 0/5/10 偏移规则 | 公开刷新规则 |
| RL | 同一规则 | LLM 在规则行动时点选择合法资产 |
| LR | LLM 每日判断 WAIT/FREEZE | 行动时由公开规则选择 |
| LL | LLM 每日判断 | LLM 选择 |

四系统各自读取实际 policy 轨迹，模块替换后轨迹会分叉，差值是系统效果，
不是同一状态上的纯认知贡献。当前观测消融只移除此前四帧，预算与完整动作记录
保留；当前帧已有三日统计，不叫完全无历史。每 episode 新会话，无隐藏供应商记忆。
严格 JSON、未知目标、额外字段和不合法模型动作记错后 WAIT；传输异常停止并
保留状态，不能当作模型主动 WAIT。成功请求从持久化回执复用。

正式研究仍计划四个固定模型配置，M1/M2 两系列强配置、M3/M4 同一开放系列
大/小配置；代表模型预选 M1/M3。精确 ID、路由、提示、解码、推理/token/费用上限
及全部比较必须在 test 前共同冻结。当前仅有 Qwen 开发批次，四席位尚未冻结。
不能依 test 表现选代表模型、改样本或删比较。

确认性家族分别为：四模型与 P* 比较 K=4；两个代表模型各做 RL−RR、LR−RR、
LL−validation 预选较强混合系统、五帧 LL−当前帧 LL，共 K=8。
同时提供普通 95% 和 Bonferroni 水平 `1−0.05/K` 的配对区间，两家族不构成
一次整体 95% 保证。模型数调整必须发生在 test 前，联动修改 K。

联合清单的核心是 10 个模型单元：四席位各一个主 LL，M1/M3 各做 RL、LR 和
当前帧 LL。RR 复用 `alarm_refresh`，代表模型五帧 LL 复用主表；历史消融属于核心
单元。所有单元仍须完整配置和联合冻结，当前不表示正式执行已经放行。

附加诊断通过 `additional_diagnostic` 显式选择。草案的 `None` 表示尚未决定，
预检必须阻止冻结；最终须填 `none`（明确不追加），或在 `rename_reorder`、
`liquidity`、`benign_spread` 中选择一项。选择一项增加 M1/M3 两个单元，共 12 个；
选择 `none` 保持 10 个。未选诊断明确延期或取消，不能把原全部诊断清单当作当前
必做合同，也不能看 test 结果再改变选择：

- 呈现：三资产一致换名/换序，同步历史、消息汇总和动作反映射；同物理动作重放
  必须保持世界与计分一致，ID 平局引起的规则变化单列。
- 流动性：目标资产 `daily_execution_liquidity` 12000→9000；独立 16 开发、128
  确认社会，两条件，不改其余主合同，不并入主表。
- 良性传播：攻击关闭，普通 `post_probability` 0.1→0.3，强度 0.2 不变；独立
  16 开发、128 确认社会，仅正常条件，不套主任务 0.5/0.5。

仅选择 `liquidity` 或 `benign_spread` 时，联合预检要求该项独立扩展合同和清单；
`none` 或 `rename_reorder` 不要求条件扩展合同。选中的条件扩展仍需独立原始与
派生 seed 审查、守恒、整体事件和公开控制检验，不能继承主任务效度。工程接口
已能处理某项扩展不表示其科学实验已经完成。

原四模型、四格、历史加全部三项诊断的 inventory 上限为 179,712 次常规 LLM
请求，未含开发/失败/重试；它是原全量设想，不是当前未选择草案的执行范围。
核心 10 单元上限为 125,952 次，选择单项后的请求上限由联合清单重算；任何数值
都不是调用授权或预算承诺。`configuration_complete` 仅表示结构预检通过，真实
供应商/费用证据、共享预算账本和研究执行冻结完成前，付费与正式 test 门禁仍关闭。
当前 Qwen 开发合同与暂停状态见 [EXPERIMENT_STATUS.md](EXPERIMENT_STATUS.md)。

## 复现和结论边界

完整成绩须有全网格、三世界原始账户/金融功能重算、公开输入/动作重放、文件指纹
和费用账本审计。缺失/失败轨迹不能删除后发布成功子集排名。`complete` 或工程
acceptance 不能自动代替科学收口、联合冻结或发布许可。

历史协议和源码字节由本地数据 manifest、源码归档及回执保存；本文统一当前口径，
不重写旧 manifest、失败标志或费用账本。整理后恢复旧运行须先核对依赖与指纹。

研究保持金融市场风险干预范围，不继续调整市场、攻击强度、人口或事件阈值追分，
不扩展任务分类、语言生成或训练基础设施。不能由一次 PPO/LLM 弱结果声称任务
不可学习，也不能要求 LLM 必须胜规则。当前外部市场校准和现实监管效果仍未验收。
